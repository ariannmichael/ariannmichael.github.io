# public/models

Kenney assets (https://kenney.nl), licensed **CC0**.

Everything in this folder is **generated by `npm run models`** (`web/scripts/prepare-models.mjs`, kit table in `web/scripts/kits.config.mjs`). **Do not hand-edit**: the script deletes and rewrites each kit folder.

- `<kit>/<model>.glb`: meshopt-compressed (`EXT_meshopt_compression`), raw Kenney units (apply the kit scale at runtime), with no embedded palette texture.
- `<kit>/colormap.webp`: the kit's shared 512×512 palette texture (textured kits only).
- Manifest with metre bounds: `web/src/world/models/manifest.generated.ts`.
